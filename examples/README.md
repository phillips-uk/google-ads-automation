# Examples

These scripts are real implementations built for specific client accounts. They are published as reference examples — they will not run without modification, as they contain client-specific container IDs, account IDs, and domain names.

Use them as starting points for your own implementations.

| Script | What it demonstrates |
|---|---|
| `gtm_ec_fix.py` | Building an Enhanced Conversions pipeline (capture → push → sequencing) via GTM API |
| `gtm_consent_mode_setup.py` | Deploying Consent Mode v2 Default State + Consentik CMP tag via GTM API |
| `gtm_trigger_fix.py` | Programmatic trigger creation and tag wiring via GTM API |
| `gtm_capture_tag_fix.py` | Updating GTM tag configuration via API |
| `gtm_shopify_ecommerce_setup.py` | Full GTM container setup for a Shopify ecommerce store |
| `gtm_shopify_event_tags.py` | Adding GA4 ecommerce event tags (view_item, add_to_cart, etc.) via GTM API |
| `gtm_shopify_purchase_pixel.js` | Shopify Custom Pixel template for server-side purchase attribution |
| `shopify_gtm_install.py` | Installing GTM snippet into a Shopify theme via Admin API |
| `shopify_oauth.py` | One-time Shopify OAuth token exchange flow |
| `conversion_cleanup.py` | Managing Google Ads conversion action status and attribution models |
